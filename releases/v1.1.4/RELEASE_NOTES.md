# VideoMatrix v1.1.4

## What's New

### Update installer improvements

- **Reveal in Finder** — when automatic installation isn't possible, the update prompt now shows a "Reveal in Finder" button that highlights the downloaded DMG file directly in Finder, instead of just opening the Downloads folder
- **Versioned filename** — the downloaded DMG is now saved as `VideoMatrix-1.1.4.dmg` (version-stamped), so it won't conflict with older downloads already in your Downloads folder
- **Exact path shown** — the full save path is displayed in the prompt so you always know exactly where to find the file
- **Improved error handling** — if saving to Downloads fails, the app falls back to showing the temp location instead of silently failing
