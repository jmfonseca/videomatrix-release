# VideoMatrix v1.1.2

## What's Changed

- **Auto-update improvement**: Removed the admin password prompt (osascript) from the update installer. If the app directory is not writable, the update DMG is now saved to your Downloads folder with a prompt to install manually.

## Installation

1. Download `VideoMatrix.dmg`
2. Double-click to mount
3. Drag VideoMatrix to Applications
4. Launch from Applications
